## Main flow

```
RENCANA → PERSIAPAN → PELAKSANAAN KBM → ASESMEN → ANALISIS → EVALUASI → ARSIP
```

## Teacher Daily Workflow

### A. Morning Dashboard
- Jadwal Hari Ini
- Kelas Berikutnya
- Agenda Rapat
- Tugas Belum Selesai
- Notifikasi Siswa
- Quick Action (Mulai KBM, Absensi, Buka Materi, Buat Quiz, Catatan, Input Nilai)

### B. Workflow Persiapan
- Lesson Planner (tujuan, CP/TP/ATP, materi, metode, media, aktivitas)
- Material Browser (cari, simpan, screenshot, catat sumber)
- AI Assistant (contoh soal, LKPD, rangkuman, stimulus, rubrik)

### C. Workflow KBM
- Start Class Mode → kelas + materi + waktu otomatis
- Attendance (Hadir/Izin/Sakit/Alpha + catatan perilaku)
- Teaching Workspace: Materi + Catatan + Whiteboard
- Teacher Notes (catatan pribadi refleksi)

### D. Quiz/Assessment
- Create: pilih kelas → buat soal → jenis (PG/PG kompleks/B-S/Essay/HOTS) → publish
- Execution: guru start → siswa kerjakan → auto collect → analisis
- Manual: essay/projek/presentasi dengan rubrik

### E. Student Analytics
- Akademik (rata-rata, perkembangan, materi sulit)
- Individu (kekuatan, kesulitan, rekomendasi)

### F. Meeting
- Catatan aktif → AI summary → action items

### G. Administration
- Tahun > Kelas (X, XI, XII) > dokumen/RPP/LKPD/bank soal/nilai/arsip

### H. End of Day
- Daily Report per kelas: materi selesai, absensi, evaluasi, catatan remedial

## Launcher mode (long-term)
