## Identity

- **Name:** 8bitOS
- **Category:** Teacher Operating System
- **Concept:** Unified digital workspace for teachers on a Huawei MatePad. Single app replaces browser + notes + docs + spreadsheets + quiz tools.

## Philosophy

> "One Device. One Workspace. Complete Teaching Workflow."

## Name meaning

- **8bit** = creativity, simplicity, tech nostalgia, innovation, unique visual identity (NOT a game reference).
- **OS** = Operating System for teaching work. Does NOT replace Android; sits on top.

## Vision

Become the digital work platform that helps teachers teach more effectively, creatively, and in an organized way, through one device.

## Mission

1. Reduce teacher dependence on many apps.
2. Unify all KBM activities.
3. Maximize tablet + stylus tech.
4. Help teachers make learning more engaging.
5. Provide automatic documentation of the whole learning process.

## Teacher cycle

```
PLAN → PREPARE → TEACH → ASSESS → REPORT
```

## Core modules

A. **Dashboard** — today's schedule, next class, tasks, agenda, notifications.
B. **Classroom Management** — class list, students, attendance, class notes, history.
C. **Teaching Planner** — learning objectives, materials, methods, media, activities, reflection.
D. **Smart Workspace** — Smart Notes (text/image/handwriting/math/voice), Whiteboard, Internal Browser.
E. **Assessment Center** — question bank, quiz, daily tests, grading, analysis.
F. **Gradebook** — tasks, quizzes, tests, projects, final grades.
G. **Document Center** — modul ajar, LKPD, soal, evaluation results, reports. Output PDF/Excel/Print.
H. **AI Teacher Assistant** — prep, question generation, evaluation, documentation.

## Huawei MatePad integration

- MatePad = "Teacher Terminal"
- Stylus: write, draw, annotate, write math formulas
- Split Workspace: PDF + Notes + Timer side by side

## Future: Launcher mode

8bitOS can become an Android launcher. Tablet boots directly into 8bitOS workspace instead of normal home screen.

## Initial technology

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, PWA, Capacitor (mobile)
- **Backend:** Supabase / InsForge
- **Storage:** IndexedDB, Cloud Sync

## Roadmap

- **Phase 1 — Foundation:** Dashboard, tablet layout, Classroom, Notes, Browser, Library.
- **Phase 2 — Teaching Workflow:** Planner, Material, Quiz, Assessment, Gradebook.
- **Phase 3 — Intelligence:** AI Assistant, learning analytics, document generator.
- **Phase 4 — Device Integration:** MatePad optimization, stylus, offline mode, launcher mode.

## Design principles

1. Help teachers work faster.
2. Reduce app switching.
3. Leverage tablet advantages.
4. Simple experience.
5. Keep focus on teaching process.
